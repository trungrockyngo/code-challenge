# Problem 2: Fancy Form (Currency Swap)

A modern, responsive DeFi-style currency swap interface built with React, TypeScript, Vite, and Tailwind CSS.

## Features
- **Live Rate Computation:** Dynamically fetches live exchange rates from the Switcheo API and calculates output values.
- **Searchable Token Modal:** Interactive token selection modal with instant symbol/name filtering.
- **Interactive Validation:** Real-time form validation with custom error handling and simulated backend delay.
- **Dark Glassmorphism UI:** Tailored Web3 aesthetic featuring responsive containers, rate badges, and interactive feedback.

## Setup & Execution
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Build for production: `npm run build`
